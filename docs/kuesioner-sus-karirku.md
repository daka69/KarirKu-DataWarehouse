# Kuesioner System Usability Scale (SUS) — Dashboard KarirKu

Status: DRAF, menunggu persetujuan Badjradaka atas pemilihan SUS.
Dibuat: 14 November 2026, sebagai instrumen untuk subbab 2.10.3 dan 3.6
laporan UAS BI Bidang MTI. Instrumen ini disebar pada Minggu 3, setelah
dashboard dapat dipakai. Responden mencoba dashboard terlebih dahulu
sebelum mengisi kuesioner.

## Petunjuk pengisian

Kuesioner ini berisi 10 pernyataan tentang dashboard KarirKu. Pilih satu
jawaban untuk setiap pernyataan pada skala berikut.

1 = Sangat tidak setuju
2 = Tidak setuju
3 = Netral
4 = Setuju
5 = Sangat setuju

Tidak ada jawaban benar atau salah. Jawaban menggambarkan pengalaman
responden saat memakai dashboard.

## Tugas sebelum pengisian

Responden menjalankan tiga tugas berikut pada dashboard, lalu mengisi
kuesioner.

1. Membaca KPI: sebutkan satu angka KPI yang tampil pada dashboard,
   misalnya jumlah lowongan atau median gaji untuk satu jabatan.
2. Memakai filter: terapkan satu filter, misalnya berdasarkan state atau
   jabatan, dan sebutkan hasil yang berubah.
3. Drill-down: buka detail satu perusahaan dari tampilan ringkasan dan
   sebutkan satu temuan dari detail tersebut.

## 10 butir pernyataan

Butir ganjil menyatakan hal yang positif tentang dashboard, dan butir
genap menyatakan hal yang negatif. Penomoran dan polaritas mengikuti
instrumen standar Brooke (1996).

1. Saya ingin sering menggunakan dashboard KarirKu ini.
2. Saya merasa dashboard KarirKu ini terlalu kompleks tanpa alasan
   yang jelas.
3. Saya merasa dashboard KarirKu ini mudah digunakan.
4. Saya merasa membutuhkan bantuan orang teknis untuk dapat
   menggunakan dashboard KarirKu ini.
5. Saya merasa berbagai fungsi dalam dashboard KarirKu ini
   terintegrasi dengan baik.
6. Saya merasa ada terlalu banyak ketidakkonsistenan dalam
   dashboard KarirKu ini.
7. Saya membayangkan sebagian besar orang akan cepat belajar
   menggunakan dashboard KarirKu ini.
8. Saya merasa dashboard KarirKu ini sangat merepotkan untuk
   digunakan.
9. Saya merasa sangat percaya diri saat menggunakan dashboard
   KarirKu ini.
10. Saya perlu mempelajari banyak hal sebelum dapat menggunakan
    dashboard KarirKu ini.

## Responden

Responden berjumlah minimal 20 orang dan bersifat bebas, yaitu
pengguna uji yang mengoperasikan dashboard (ditetapkan pada Konsultasi 1,
16 November 2026). Data yang dikumpulkan adalah 20 responden dikali 10
jawaban, ditambah catatan tugas yang dijalankan responden.
Data mentah kuesioner dilampirkan pada Lampiran 6.

## Perhitungan skor

Skor dihitung per responden dengan langkah berikut.

- Butir ganjil: skor butir sama dengan nilai jawaban dikurangi 1.
- Butir genap: skor butir sama dengan 5 dikurangi nilai jawaban.
- Seluruh skor butir dijumlahkan, lalu hasilnya dikalikan 2,5 sehingga
  skor akhir berada pada rentang 0 sampai 100.

Skor rata-rata dari seluruh responden menjadi skor SUS dashboard. Skor
rata-rata per butir juga dihitung untuk melihat butir mana yang
paling lemah.

### Contoh perhitungan

Satu responden menjawab [4, 2, 5, 2, 4, 1, 5, 2, 4, 2].

Butir ganjil: (4-1) + (5-1) + (4-1) + (5-1) + (4-1) = 3 + 4 + 3 + 4 + 3 = 17.
Butir genap: (5-2) + (5-2) + (5-1) + (5-2) + (5-2) = 3 + 3 + 4 + 3 + 3 = 16.
Jumlah skor butir = 33. Skor SUS responden = 33 x 2,5 = 82,5.

## Interpretasi

Skor SUS dibandingkan dengan ambang baku berikut. Skor di bawah 50
berarti tidak dapat diterima. Skor 50 sampai 68 berarti di bawah
rata-rata. Skor 68 adalah rata-rata industri. Skor di atas 80,3 berarti
Excellent, dan skor di atas 90,9 berarti terbaik.

## Rekomendasi

Rekomendasi diturunkan dari butir SUS yang skornya paling rendah.
Butir konsistensi yang rendah mengarah pada penyeragaman format antar
dashboard, dan butir kebutuhan belajar yang rendah mengarah pada
penambahan label dan panduan singkat di dashboard. Perbaikan tersebut
ditampilkan pada slide 9 sebagai dashboard sesudah evaluasi.
